Data package 1.10.0 (release R2026.9, built 2026-09-28). Start with gut_studies.parquet (one row per catalog study) and gut_sample_metadata_wide.parquet (one row per sample); the evidence behind every value is in gut_sample_determinations.parquet; the registry of all human shotgun metagenomes is registry_studies.parquet. Column definitions: data dictionary.

Microbiome Repo — release R2026.9 · package 1.10.0 · build 3d311a7 · built 2026-09-28 · data tag data-v1.10.0 · DOI pending Zenodo integration (VERSION.json, what changed, changelog). Curated tables (registry_*, gut_* and the infant extension) are released under CC-BY-4.0; archive metadata remains under INSDC terms; community profiles from Sandpiper (Woodcroft et al. 2025, CC-BY).
How to cite: Microbiome Repo, release R2026.9 (data package 1.10.0), OlmLab, 2026-09-28.
Caveats: every value carries a route (R1 archive attribute, R2 supplementary table, R3 paper text, R4 abstract/description), a scope and a confidence tier (not a calibrated probability); R3/R4 values are cohort-wide statements applied to the study's samples — see Fields and Methods › Limitations. Built with an LLM-assisted pipeline; treat individual values as evidence-linked claims, not ground truth. Found an error? Every study, cohort and sample has a Flag an issue button that opens a prefilled GitHub issue. Know a study's missing metadata? See Contribute.
