Reports

  • CATALOG_REPORT (markdown) — universe enumeration, triage cascade, coverage estimate, audits.
  • EXTRACTION_REPORT (markdown) — per-sample metadata extraction, four routes, gold evaluation, recovery rounds.
  • SANDPIPER_REPORT — community-profile join, method, validation.
  • AUTHORS_REPORT — author/organisation index sources and coverage.
  • DATA_MODEL_FIX_REPORT — v1.2 age-scope / parent / history fix.

Infant Gut Shotgun-Metagenome Catalog — package 1.2.1 · built 2026-09-26 · generator nogit · release data-v1.2.1 (VERSION.json, changelog). Curated tables are released under CC-BY-4.0; archive metadata remains under INSDC terms; community profiles from Sandpiper (Woodcroft et al. 2025, CC-BY).
How to cite: Infant Gut Shotgun-Metagenome Catalog, data package 1.2.1 (data-v1.2.1), 2026.
Caveats: every value carries a route (R1 archive attribute, R2 supplementary table, R3 paper text, R4 abstract/description), a scope and a confidence tier (not a calibrated probability); R3/R4 values are group-level statements applied to samples — see Fields and Methods › Limitations. Built with an LLM-assisted pipeline; treat individual values as evidence-linked claims, not ground truth. Found an error? Every study, cohort and sample has a Flag an issue button that opens a prefilled GitHub issue.
