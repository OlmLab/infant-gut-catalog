Reports

  • CATALOG_REPORT (markdown) — universe enumeration, triage cascade, coverage estimate, audits.
  • EXTRACTION_REPORT (markdown) — per-sample metadata extraction, four routes, gold evaluation, recovery rounds.
  • SANDPIPER_REPORT — community-profile join, method, validation.
  • AUTHORS_REPORT — author/organisation index sources and coverage.
  • DATA_MODEL_FIX_REPORT — v1.2 age-scope / parent / history fix.

How to cite: Microbiome Repo, release R2026.7 (data package 1.8.0), OlmLab, 2026-09-28.
Caveats: every value carries a route (R1 archive attribute, R2 supplementary table, R3 paper text, R4 abstract/description), a scope and a confidence tier (not a calibrated probability); R3/R4 values are group-level statements applied to samples — see Fields and Methods › Limitations. Built with an LLM-assisted pipeline; treat individual values as evidence-linked claims, not ground truth. Found an error? Every study, cohort and sample has a Flag an issue button that opens a prefilled GitHub issue. Know a study's missing metadata? See Contribute.
