Fields and data dictionary

Each metadata field in sample_metadata_wide comes with a companion <field>__confidence (0–1) and <field>__route (R1–R4). Coverage below counts infant-scope samples (body-site class primary or unknown) and included studies with at least one value; the route mix counts determinations in sample_determinations.

Definition caveats. antibiotic_exposure = any antibiotics to the infant before or at sampling (sources that record only current use disagree; precision 0.87 against that definition). feeding_mode categories differ between sources (precision 0.89). Exposure fields (probiotic, HMO, NEC, birth weight, maternal antibiotics) have no external truth set and were audited by blind model re-judgement only. Extension fields (health_condition, multiple_birth, sibling_in_study, geo_subregion) were added in one pass and are less audited. R3/R4 values are group statements applied to samples — use them only at confidence ≥ 0.5.

Routes

R1 = archive sample attribute or sample-name convention (per sample); R2 = supplementary table row (per sample; 'subject_level_join' in parse_note when copied from a per-subject row); R3 = statement in the paper text applied to a defined group; R4 = abstract/ENA description statement (group; confidence ≤0.5).
