Registry: all human shotgun metagenomes

The registry tier lists every public ENA study with shotgun-metagenome runs and a human signal — all body sites, all ages (54,410 studies, 1,984,314 runs, 1,699,589 BioSamples in release R2026.8). Each study carries archive-only metadata (route R1): host, body site(s) anchored to UBERON, life stage(s), assay, access, and the classification stage that produced them. The curated tier goes deeper — per-sample fields recovered from supplementary tables and papers (routes R2–R4) — and is built scope by scope; the infant gut catalog (389 included studies with study pages) is the first curated scope. Registry classification is cheap (deterministic rules plus one replicated model pass per study) and is meant to be immediately useful for finding studies; exclusion is reserved for non-human, non-metagenome and non-shotgun deposits.

Registry rows are classifications, not inclusions: a study can carry several body sites and life stages. Every committed site or stage value carries an evidence row (labelled source, ≤ 12-word quote); rows at stage pending have not been classified yet and are shown for completeness. See Methods › Registry classification for the cascade, the vocabularies and what the confidence means.
