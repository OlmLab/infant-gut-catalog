src_track pipeline pass that produced the row

Routes

R1 = archive sample attribute or sample-name convention (per sample); R2 = supplementary table row (per sample; 'subject_level_join' in parse_note when copied from a per-subject row); R3 = statement in the paper text applied to a defined group; R4 = abstract/ENA description statement (group; confidence ≤0.5).

Infant Gut Shotgun-Metagenome Catalog — data package v1 (built 2026-09-25). Curated tables are released under CC-BY-4.0; archive metadata remains under INSDC terms.
How to cite: Infant Gut Shotgun-Metagenome Catalog v1, 2026.
Caveats: every value carries a route (R1 archive attribute, R2 supplementary table, R3 paper text, R4 abstract/description) and a confidence; R3/R4 values are group-level statements applied to samples — see Fields and Methods › Limitations. Built with an LLM-assisted pipeline; treat individual values as evidence-linked claims, not ground truth.
