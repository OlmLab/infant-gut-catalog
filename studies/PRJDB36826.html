Archive description

This project encompasses metagenomic sequencing data derived from fecal samples of healthy individuals aged 20 - 25 years. The data underwent rigorous quality control. Post-quality control, the sequencing reads were aligned to the host genome to remove those that matched the host genome. Subsequently, taxonomic classification was performed using a customized Kraken2 microbial database.
